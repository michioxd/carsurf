# CarSurfExtended

A fork of [CarSurf](https://github.com/pavunato/carsurf) with added support for ultrawide screen head units. Run any app on your CarPlay display — a CarBridge-equivalent tweak rebuilt for the modern (iOS 15–18) CarPlay pipeline.
